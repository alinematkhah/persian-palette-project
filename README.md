# Landed with Love

یک لندینگ پیج حرفه‌ای و مدرن با محتوای این فایل برام ایجاد کن. عکس لوگوم و سه عکس از تصاویری که میتونی استفاده کنی رو برات قرار دادم (از تصویری که داخلش 4 آدم وجود داره در hero استفاده کن). زبان فارسی باشه. قانون 60،30 و 10 در انتخاب رنگ رو رعایت کن. تم لایت و دارک رو همزمان داشته باشه.
